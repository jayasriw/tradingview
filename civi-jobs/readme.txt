== Description ==

CiviJobs is a complete job board WordPress theme designed for employment platforms,
recruitment agencies, and freelancer marketplaces.

**Key Features:**
* Employer & Candidate Dashboards
* Advanced Job Search with AJAX Filters
* Interactive Jobs Map (Leaflet.js)
* Company Profiles with Reviews & Ratings
* Private Messaging System
* Meeting/Interview Scheduling
* Job Alerts with Email Notifications
* Freelancer Marketplace with Wallet System
* Membership Packages (WooCommerce)
* Admin Management Panel
* Fully Responsive Design
* 10 Custom Database Tables

== Installation ==

1. Upload the `civi-jobs` folder to `/wp-content/themes/`
2. Activate the theme in WordPress Dashboard → Appearance → Themes
3. The required database tables will be created automatically on activation
4. Create pages using the provided page templates:
   - Home: Template Name: Home
   - Jobs: Template Name: Jobs Listing
   - Companies: Template Name: Companies Listing
   - Candidates: Template Name: Candidates Listing
   - Pricing: Template Name: Pricing
   - Jobs Map: Template Name: Jobs Map
   - Login: Template Name: Login
   - Register: Template Name: Register
   - Employer Dashboard: Template Name: Employer Dashboard
   - Candidate Dashboard: Template Name: Candidate Dashboard

== Recommended Plugins ==
* WooCommerce (for membership packages and payments)
* WP Mail SMTP (for reliable email delivery)
